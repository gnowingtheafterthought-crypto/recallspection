# Security Policy

Recallspection is a cryptographic memory system for AI agents. Security and data integrity are our top priorities.

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 18.0.x | ✅ |
| < 18.0 | ❌ |

## Reporting a Vulnerability

**Do not file a public GitHub issue for security vulnerabilities.**

Please report vulnerabilities via email to:

**eli@example.com** (replace with your actual email)

### What to include:
- A clear description of the vulnerability
- Steps to reproduce (code snippets, API calls)
- Affected versions
- Potential impact
- Your preferred disclosure timeline

### Response SLA:
| Severity | Response Time | Fix Timeline |
| :--- | :--- | :--- |
| **Critical** (RCE, data breach) | 24 hours | 48 hours |
| **High** (auth bypass, tampering) | 48 hours | 1 week |
| **Medium/Low** (performance, edge cases) | 1 week | Next release |

### Disclosure Policy
We follow **responsible disclosure**:
1. We will acknowledge receipt within 24 hours.
2. We will keep you updated on the fix progress.
3. We will credit you in the release notes (unless you prefer to remain anonymous).
4. Public disclosure happens **30 days** after the fix is released, or sooner if you consent.

We take every report seriously. Thank you for helping keep Recallspection secure.
