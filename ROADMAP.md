# 🗺️ Recallspection Roadmap

## ✅ v18.0.0 (Released Aug 2026)
- [x] ExactCore (SHA3-256 + zlib) cryptographic hash table
- [x] SemanticCore (Sentence Transformers + FAISS)
- [x] Exact-First Routing logic
- [x] 10,000 fact benchmark (100% accuracy)
- [x] Public release + AGPLv3 license

## 🚀 v18.1.0 (Q4 2026)
- [ ] **Async API support** – Non-blocking writes/reads for production workloads
- [ ] **Redis backend** – Optional in-memory caching for sub-0.1ms lookups
- [ ] **Docker image** – One-command deployment
- [ ] **REST API documentation** – OpenAPI/Swagger for the Render instance
- [ ] **LangChain integration** – Official `langchain-memory` adapter

## 🌟 v19.0.0 (Q1 2027)
- [ ] **Multi-tenancy** – Isolated memory spaces per user/organization
- [ ] **Audit trail** – Cryptographic proof of *when* a fact was retrieved
- [ ] **Federated memory** – Sync across multiple Recallspection nodes
- [ ] **Web UI dashboard** – Visualize stored facts and query history

## 🔮 Future (Beyond v19)
- [ ] **Zero-knowledge proofs** – Verify retrieval without revealing the fact
- [ ] **On-chain verification** – Ethereum smart contract integration for immutable audit logs
- [ ] **Multi-modal memory** – Store and retrieve images, audio embeddings
